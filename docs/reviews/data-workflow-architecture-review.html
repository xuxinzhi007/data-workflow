G7 走这里

Problem　会话钩子把 next 当只读探针，show 在产物齐时却会推进并写记录；同一条路径还不调用只挂在 done 上的 G7。

Solution　加深运行状态：查询与推进分成两条不相漏的路径，阶段能不能离开（含 G7）只在推进这一侧判定。

  • Wins　locality: 写盘只发生在推进
  • locality: G7 跟其它门同路
  • leverage: 钩子与 next 共用只读路径

产物落点 · deep

按声明的根解析占位符

<artifacts_root> · <feature> · <topic>

docs/reviews/… 或 specs/<feature>/…

Problem　JSON 声明了 artifacts_root，runner 不读这个字段，把占位符写死成 specs/<feature>，<topic> 也不替换；layout 里的同名键是另一件事。

Solution　加深产物落点：机器门按工作流声明的根去找文件，占位符在一处解析完。

  • Wins　locality: 落点规则只在一处
  • leverage: 新工作流声明根即生效
  • locality: 同名键不再对不上
